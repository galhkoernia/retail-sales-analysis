# Data Cleaning

## Tujuan

Menyiapkan dataset agar siap digunakan pada proses analisis.

---

## Pemeriksaan

Tahapan yang dilakukan meliputi:

- Missing Values
- Duplicate Data
- Data Type Validation
- Invalid Values
- Konsistensi kategori
- Format tanggal

---

## Prinsip Cleaning

Data hanya dibersihkan apabila ditemukan masalah.

Tidak dilakukan manipulasi data yang dapat mengubah makna bisnis dari dataset.
