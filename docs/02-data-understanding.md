# Data Understanding

## Dataset Overview

Dataset berisi transaksi penjualan perusahaan retail global.

Setiap baris merepresentasikan satu transaksi penjualan.

Dataset mencakup informasi mengenai:

- Order
- Produk
- Customer
- Lokasi
- Waktu
- Penjualan

---

## Tahapan Data Understanding

Analisis awal dilakukan untuk memahami kualitas data melalui:

- Dimensi dataset
- Struktur kolom
- Tipe data
- Missing Values
- Duplicate Data
- Statistik deskriptif

---

## Output

Pada tahap ini diharapkan diperoleh pemahaman mengenai kualitas data sebelum dilakukan proses pembersihan data.
